# Explain

The output is understanding, not a change. Every diagram carries its badge; every claim cites code or history.

1. **explain-pr** for a diff, branch or PR; **teach** for a subsystem or concept
   Done: the explanation exists (page path or reply), each panel badged, and the user's question is answered.
2. **quiz** (optional)
   Done: cards given if the user wants them; otherwise `skip: not requested`.
3. **learning-check**
   Done: its result is stated in the reply; silence is not a result.

**Reply:** the page path or the explanation, and what to read first.
